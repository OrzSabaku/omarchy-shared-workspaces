# Development

This package restores Omarchy 4.0.6 global workspace behavior on Omarchy 4.5.
Keep changes limited to workspace navigation and its bar widget. Never renumber
or merge live workspaces, edit /usr/share/omarchy, or overwrite user configuration.
Keep the bar-only plugin out of plugins[]; enable it with the normal plugin CLI.
Keep upstream attribution. Run the README checks before publishing.
Report mocked verification separately from live desktop results. Changes to
Omarchy internals require inspection of the installed source and old package.
